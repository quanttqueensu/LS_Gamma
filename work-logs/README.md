# Work logs

One log per analyst: a short record of each work session, backed by links to the actual work.

## How to log
At the end of every work session, open Claude Code in the repo and run **`/log-work`**.
1. Claude collects your evidence since your last entry: commits, cards, experiments, code, and work in progress.
2. You write a 2–4 sentence update **in your own words**: what you did, what you learned, and what's next or blocking you.
3. Claude adds the entry to `work-logs/<your-handle>/YYYY-MM.md` and offers to commit it. Then you `git push`.

The first time, Claude asks for your GitHub handle (and topic) and fills in your row below.

## Rules
- **The update is yours.** Claude gathers the evidence but never writes or edits your update.
- **Log every session**, including reading and meetings. An entry with no commits is fine.
- **Don't edit old entries.** If something was wrong, say so in the next one.
- No Claude Code? Copy the entry format from `.claude/skills/log-work/SKILL.md` and fill it in yourself.
